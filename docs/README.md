## ルールの変更

- `docs/` のルールやテンプレートを変えるときも、PR で行う
- 全員に関わるので、PR を出したら Discord で告知し、意見を募る
- GitHub の設定（Ruleset など）を変えるときは、先にルールを変える PR で合意してから設定する
