# AI（Claude Code など）を使うときのルール

このドキュメントでは、Claude Code などの AI を使って開発するときのルールを定義する。
AI に任せる部分と人間が責任を持つ部分を分け、AI による事故を防ぐことが目的。

- AI に作業させる前に、自分で作業ブランチを切っておく（AI に `main` / `develop` で直接作業させない）
- AI が push・PR 作成・Issue 操作をするときは、必ず人間が内容を確認してから実行させる
- AI に PR を作らせるときは、[PR テンプレート](../.github/pull_request_template.md) の見出しに沿って日本語で本文を書かせる（コマンドで作ると、テンプレートが自動で入らないため）
- AI が書いたコードやコミットも、自分が書いたものとして責任を持ってレビューする
- AI が関わったコミットには `Co-Authored-By:` 行を付けたままにする（どこを AI に任せたか後から振り返れるようにするため）
